# Transformer 基础概念笔记（W02）

## 1. Token（词元）

- **定义**：模型处理文本的最小单位，可能是一个词、半个词、子词或标点；中文常按字/词切成子词。Token 不等于字符，也不等于单词。
- **对输出的影响**：计费与上下文长度都按 Token 计；输入/输出 Token 数量直接决定成本和能容纳的内容长度。
- **我的理解**：

## 2. Tokenizer（分词器）

- **定义**：把原始文本切成 Token 序列、再映射成模型输入 ID 的组件；输出阶段再把 ID 还原成文本。不同模型有不同分词器。
- **对输出的影响**：分词粒度影响同一内容占用的 Token 数；生僻字、代码、混合语言可能被拆成更多子词，改变长度与表达。
- **我的理解**：

## 3. 上下文窗口（Context Window）

- **定义**：模型一次能看到的最大 Token 数（输入 + 输出合计）。超出部分会被截断或需要摘要/检索。
- **对输出的影响**：窗口装不下时，靠前的信息会丢失，模型可能「忘记」前文；选择模型时要按任务最长对话 + 输出估算窗口。
- **我的理解**：

## 4. 自注意力机制（Self-Attention）

- **定义**：让模型在生成每个词时，对前文不同位置分配不同关注权重（哪些词与当前词相关），从而理解句子内部的指代与关系。
- **对输出的影响**：注意力决定模型抓得住哪些上下文线索；长距离依赖、指代消解、歧义理解都依赖它。
- **我的理解**：

## 5. 温度 Temperature

- **定义**：控制输出随机性的采样参数，取值通常 0–2。值越低分布越集中，越高越发散。
- **对输出的影响**：低温度→稳定、确定、偏保守（适合抽取/代码）；高温度→多样、有创意但可能跑偏或胡编（适合写作/头脑风暴）。

## 6. Top-p（核采样）

- **定义**：另一种采样策略，只在累计概率达到 p 的最小候选集合里选词，动态按概率截断长尾。
- **对输出的影响**：p 越小越保守；与温度配合控制多样性。常把一个调低、另一个保持默认，避免双重随机导致输出失控。
- **我的理解**：

## 7. Top-k

- **定义**：每次只在概率最高的 k 个候选 Token 里采样，k 是固定数量阈值。
- **对输出的影响**：k 小→候选少、输出稳；k 大→候选多、更随机。它是按数量截断，Top-p 是按概率截断。
- **我的理解**：

## 8. 最大输出长度 max_tokens

- **定义**：限制本次回复最多生成的 Token 数；是输出侧上限，不含输入。
- **对输出的影响**：设太小会在句子中途被截断（finish_reason 常为 length）；设太大会拉长耗时与费用。需结合任务体裁预留空间。
- **我的理解**：

## 9. 系统提示词 System Prompt

- **定义**：位于对话最前、用于设定角色、语气、规则与边界的指令，优先级通常高于用户消息。
- **对输出的影响**：决定模型的身份定位、回答风格与约束（如「只用 JSON」「不要透露内部信息」）；写得越明确，输出越可控。
- **我的理解**：

## 10. 停止词 Stop

- **定义**：一组触发模型提前停止生成的字符串；一旦出现就结束本次输出。
- **对输出的影响**：可用来在固定分隔符、模板标签处截断，避免多余续写；设置不当可能误停在正常内容中间。
